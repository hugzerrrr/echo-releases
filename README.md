## Installer Echo

| Système | Fichier | Installation |
|---|---|---|
| **Windows** 10 et 11 | [Echo-Setup.exe](https://github.com/hugzerrrr/echo-releases/releases/latest/download/Echo-Setup.exe) | Lancez le fichier, cochez les applications voulues, puis « Installer ». |
| **macOS** 11 ou plus récent<br>Intel et Apple Silicon | [Echo-macOS.dmg](https://github.com/hugzerrrr/echo-releases/releases/latest/download/Echo-macOS.dmg) | Ouvrez le fichier et glissez Echo dans le dossier Applications. |
| **Linux** | [Echo-Linux.zip](https://github.com/hugzerrrr/echo-releases/releases/latest/download/Echo-Linux.zip) | Décompressez l'archive et lancez `echo-launcher`. |

> **Première ouverture.** Echo n'est pas encore signé par Microsoft ni par Apple.
> - Windows : si un avertissement apparaît, cliquez sur « Informations complémentaires », puis « Exécuter quand même ».
> - macOS : si l'ouverture est bloquée, allez dans Réglages Système › Confidentialité et sécurité › « Ouvrir quand même ».

Les applications s'installent depuis Echo, en un clic.

## Mises à jour

Echo recherche les nouvelles versions à son ouverture, puis toutes les six heures. Il vous les **propose** : rien ne s'installe sans votre accord. Echo se met aussi à jour lui-même.

## Confidentialité

Chaque fichier est vérifié (somme SHA-256) avant l'installation. Echo n'envoie aucune information sur vous ni sur votre compte : il lit seulement la liste des versions publiées.

## Versions

Les versions d'Echo, avec leurs notes, sont sur la page [Releases](https://github.com/hugzerrrr/echo-releases/releases). Ce sont des versions de test.
